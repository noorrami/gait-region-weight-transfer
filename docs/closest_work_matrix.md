## Interpretation

Regional weighting, fusion, and reuse of fixed weights are not novel claims. The defensible candidate contribution is a narrowly controlled evaluation of whether **bag-selected** fixed regional weights transfer to **coat** probes on excluded identities, and whether they outperform equal fusion, lower-only scoring and weights selected from normal walking. Full 2010/2013 protocol checks and forward citation review remain necessary.

The 2017 normal-weight result motivates a planned secondary **NM-selected weight** control. Keep the primary BG-versus-equal estimand unchanged. Select the control weight on validation NM05-06 using the same fixed regional representations; no coat data are used. This control is not a replication of the 2017 nine-classifier decision fusion.

Do not compare headline accuracies across these papers and our planned 50/24/50 participant roles. Different feature pipelines, views, galleries and fitting identities invalidate an unqualified ranking. No external paper's accuracy is copied into a table as if obtained by our code.
