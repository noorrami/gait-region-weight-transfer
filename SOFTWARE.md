# Software and method attribution

Scientific implementation uses NumPy, SciPy and Pillow; pytest checks synthetic fixtures. Versions are in requirements.txt. SciPy permutation_test documentation: https://docs.scipy.org/doc/scipy/reference/generated/scipy.stats.permutation_test.html (software cross-check only).

Methodological source: A. M. Winkler et al., Permutation inference for the general linear model, NeuroImage 92, 381–397, 2014. DOI: 10.1016/j.neuroimage.2014.01.060. This supports assumptions and sign-flip methodology, not proof those assumptions hold in this dataset.
